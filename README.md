# Planning Eliot

Appli perso : journée 00h–24h en 5 colonnes, to-do, entraînements (salle, tennis, cardio), semaine type et suivi des partiels.

## Mettre en ligne (GitHub Pages)
1. Crée un dépôt public `planning-eliot` sur GitHub.
2. *Add file → Upload files* : envoie **le contenu** du dossier (index.html, manifest.webmanifest, apple-touch-icon.png, dossier icons). Commit.
3. *Settings → Pages* : Source = *Deploy from a branch*, branche `main`, dossier `/ (root)`. Save.
4. Après 1 à 2 minutes, l'appli est sur `https://<ton-pseudo>.github.io/planning-eliot/`.

## Écran d'accueil (iPhone / iPad)
Ouvre l'adresse dans Safari → bouton Partager → *Sur l'écran d'accueil*.

## Données
Cette version garde tes données sur l'appareil (stockage du navigateur). Elles ne se synchronisent pas entre iPhone et iPad, et ne sont pas partagées avec la version Claude de l'appli.
